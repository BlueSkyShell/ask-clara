Reliability benchmarks

Two suites, each case run 3×. The safety verdict is deterministic by design — so verdict accuracy is a property of the engine, not the model. The model-dependent numbers are narration quality and how a small model handles ambiguous and adversarial requests.

Explain — did it catch the drains?

20 labelled transactions (12 malicious drain patterns, 8 safe), 3 runs = 60 evaluations. A false negative — a missed drain — is the costly error, so it leads.

Construct — did it build the right thing, and refuse the traps?

26 natural-language requests: clean, ambiguous, adversarial. The only true failure is an incorrect action — building a transaction that shouldn't exist. Refusing or asking to clarify when a build was expected is a “safe miss”, reported but not dangerous.
