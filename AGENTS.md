# Crecimiento Hackathon

Hackathon context lives in three files in this directory — read them before doing any work here:

- [rules.md](./rules.md) — registration, hacking rules, minimum submission requirements
- [judging.md](./judging.md) — timeline, judging process, scoring criteria
- [tracks.md](./tracks.md) — the four prize tracks (WDK, Pears, QVAC, General), their requirements, and submission checklists
- [research.md](./research.md) — prior art per track (past hackathons, official examples, showcases) — read before brainstorming, so ideas don't duplicate something that already exists or already won
- [judging-pattern.md](./judging-pattern.md) — inferred scoring emphasis per track, based on each judge's background and the sponsor's own stated criteria
- [concept.md](./concept.md) — the chosen project concept, track entry, and submission checklist
- [ideas.md](./ideas.md) — 50 brainstormed project ideas (QVAC track, mixed with WDK/Pears/General tech)
- [agent-brief.md](./agent-brief.md) — single self-contained prompt packing the full project context, for priming a local coding agent
