# Rules

A global builder ecosystem in one event. A two-day hackathon where teams form, build, and ship real projects.

**Dates:** August 22–23, 2026

## Before the Hackathon

### Register

- Ensure you and all your team (if you already have one) have completed the Application Form.
- 🚨 You'll receive an email accepting your application and instructions to participate.

### Connect and Stay Up to Date

The only official communication channels are:

- X/Twitter
- Our private Telegram group chat (check your approval e-mail!)

## During the Hackathon

### Hacking Rules

- 🚨 You can plan ahead of time, but all code for your project has to be written during the hackathon. Code can only be committed after official start and until the submission deadline. Otherwise, you will be disqualified (no exception, everything will be checked).
- The decision of judges is final for determining prizes.
- A team can have between 1 and 4 members.
- You can not use another team's code.
- Breaking our Rules and Code of Conduct leads to exclusion from the event.

### Minimum Submission Requirements

- A demo is required. Show us what you built in a short video.
- Provide a link to the open-source code. Startups can apply with a new feature but the code must be open-source. Include a Readme with information about the project.
- When submitting, select on DoraHacks the Tracks or Bounties you're applying for. Explain in your application which bounties you're applying to and the contracts you're submitting.
- If you deploy a contract, the contract address must be provided.

### Asking for Help from Mentors

Mentors are available to help you build the best possible project — no question is too small or too big.
